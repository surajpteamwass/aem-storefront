# Tabs Block

A tabbed content block that allows authors to organize content into switchable panels.

## Authoring

Each row represents one tab. The first cell is the tab label, the second cell is the panel content.

| Tabs   |                              |
|--------|------------------------------|
| Tab 1  | Content for the first tab.   |
| Tab 2  | Content for the second tab.  |
| Tab 3  | Content for the third tab.   |

## Features

- Accessible with ARIA roles (`tablist`, `tab`, `tabpanel`)
- Responsive font sizing across mobile, tablet, and desktop
- Horizontal scroll when tabs overflow on small screens
- First tab is selected by default

## Variants

None. Use the base `Tabs` block name.
